Esse é um painel feito atraves de extração de dados de um banco MYsql conectado ao Metabase de forma local.
O processo é bem simples, foi criado uma view no banco e feito perguntas em SQL no metabase.
Foi também adicionado alguns filtro para comparação e busca facilitada para o usuário final que não tem afinidade com SQL.
